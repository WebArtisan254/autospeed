How to Use the API

Once you create a token, include it in the Authorization header of your requests:

List Your Entries
curl -H "Authorization: Bearer YOUR_TOKEN" \
  http://134.122.126.159/api/entries
Create an Entry
curl -X POST \
  -H "Authorization: Bearer YOUR_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"title": "My Entry", "content": "Hello from the API"}' \
  http://134.122.126.159/api/entries
Update an Entry
curl -X PUT \
  -H "Authorization: Bearer YOUR_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"title": "Updated Title", "content": "New content"}' \
  http://134.122.126.159/api/entries/1
Delete an Entry
curl -X DELETE \
  -H "Authorization: Bearer YOUR_TOKEN" \
  http://134.122.126.159/api/entries/1

Note: Replace YOUR_TOKEN with the token you receive after creating one above. Keep your token secret — treat it like a password.
